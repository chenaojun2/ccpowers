# 规格文档审查提示模板

分派规格文档审查子代理时使用此模板。

**目的：** 验证规格是否完整、一致且准备好进行实施规划。

```
Task 工具（general-purpose）：
  description: "审查规格文档"
  prompt: |
    你是规格文档审查员。验证此规格是否完整并准备好进行规划。

    **待审规格：** [SPEC_FILE_PATH]

    ## 检查内容

    | 类别 | 检查项 |
    |------|--------|
    | 完整性 | TODO、占位符、"待定"、不完整的章节 |
    | 一致性 | 内部矛盾、冲突的需求 |
    | 清晰度 | 需求是否模糊到可能导致构建错误的东西 |
    | 范围 | 是否聚焦到可以用单个计划覆盖 |
    | YAGNI | 未请求的功能、过度工程 |

    ## 校准

    **只标记会在实施规划中造成实际问题的问题。**
    除非有会导致有缺陷计划的严重缺口，否则批准。

    ## 输出格式

    **状态：** 通过 | 发现问题

    **问题（如有）：**
    - [章节 X]：[具体问题] - [对规划的影响]

    **建议（参考性，不阻止批准）：**
    - [改进建议]
```
