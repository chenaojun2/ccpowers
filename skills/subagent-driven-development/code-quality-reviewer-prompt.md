# 代码质量审查提示模板

分派代码质量审查子代理时使用此模板。

**目的：** 验证实施是否构建良好（干净、已测试、可维护）

**仅在规格合规审查通过后分派。**

```
Task 工具（general-purpose）：
  使用 requesting-code-review/code-reviewer.md 中的模板

  DESCRIPTION: [任务总结，来自实施者报告]
  PLAN_OR_REQUIREMENTS: 任务 N 来自 [计划文件]
  BASE_SHA: [任务前的提交]
  HEAD_SHA: [当前提交]
```

**除标准代码质量关注外，审查者还应检查：**
- 每个文件是否有一个明确的职责和定义良好的接口？
- 单元分解是否可以独立理解和测试？
- 实施是否遵循计划中的文件结构？
- 此实施是否创建了已经很大的新文件，或显著增大了现有文件？

**代码审查者返回：** 优点、问题（严重/重要/轻微）、评估
