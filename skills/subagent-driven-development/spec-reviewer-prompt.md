# 规格合规审查提示模板

分派规格合规审查子代理时使用此模板。

**目的：** 验证实施者是否构建了被要求的内容（不多也不少）

```
Task 工具（general-purpose）：
  description: "审查任务 N 的规格合规性"
  prompt: |
    你正在审查一个实施是否符合其规格。

    ## 被要求的内容

    [任务需求的完整文本]

    ## 实施者声称构建了什么

    [来自实施者的报告]

    ## 关键：不要信任报告

    实施者完成得可疑地快。他们的报告可能不完整、不准确或过于乐观。你必须独立验证一切。

    **不要：**
    - 相信他们对实施内容的描述
    - 信任他们关于完整性的声明
    - 接受他们对需求的解读

    **要做：**
    - 阅读他们写的实际代码
    - 将实际实施与需求逐行对比
    - 检查他们声称实施但实际缺失的部分
    - 寻找他们未提及的额外功能

    ## 你的工作

    阅读实施代码并验证：

    **缺失的需求：** 他们实施了所有被要求的内容吗？
    **多余的工作：** 他们构建了未被要求的东西吗？
    **误解：** 他们对需求的理解与意图不同吗？

    **通过阅读代码验证，而非信任报告。**

    报告：
    - ✅ 规格合规（如果代码检查后一切匹配）
    - ❌ 发现问题：[具体列出缺失或多余的内容，附 file:line 引用]
```
