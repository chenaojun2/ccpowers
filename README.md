# ccpowers

Claude Code 核心技能库（中文版）。

一套完整的软件开发方法论，通过可组合的技能和自动触发机制，让你的编码代理拥有超能力。

## 安装

将此项目克隆到本地后，在 Claude Code 中使用插件系统加载：

```bash
# 克隆项目
git clone <repo-url> ccpowers

# 在 Claude Code 中安装为本地插件
claude plugin add ./ccpowers
```

## 包含的技能

### 流程技能（决定如何做）
- **头脑风暴** — 创造性工作前的设计探索，逐步提问完善想法
- **系统化调试** — 四阶段根因分析：调查 → 模式 → 假设 → 实施

### 计划技能（组织工作）
- **编写计划** — 将规格转化为小粒度、TDD 驱动的实施计划
- **执行计划** — 按计划逐步执行，带审查检查点
- **子代理驱动开发** — 每任务派遣新子代理，两阶段审查保证质量

### 质量技能（保证质量）
- **测试驱动开发** — 红-绿-重构，先写测试后写代码
- **请求代码审查** — 分派审查子代理检查代码
- **接收代码审查** — 技术严谨地处理审查反馈
- **完成验证** — 证据先于声明，运行验证后才能说完成

### 工具技能（辅助工具）
- **并行代理调度** — 独立任务并行分派代理执行
- **使用git工作树** — 隔离工作区管理
- **完成开发分支** — 合并、PR、清理的结构化工作流

### 预留接口
- **ui-autotest** — UI 自动化测试执行与管理的能力接口，等待接入具体服务

## 工作原理

ccpowers 使用 Claude Code 的插件系统。会话启动时，`hooks/session-start` 脚本注入 `using-ccpowers` 技能内容，建立技能自动触发的规则。之后 Claude 会在适当时机自动调用相关技能。
